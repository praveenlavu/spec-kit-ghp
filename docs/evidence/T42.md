Also: the extension and bundle zips downloaded from the release are byte-identical to the ones built from a clean clone of the tag, and match `SHA256SUMS`. `ghp --version` from `uvx --from git+https://github.com/praveenlavu/spec-kit-ghp@v0.1.0` printed `0.1.0`. `specify bundle validate --path bundle` fails (exit 1) unless the two component catalogs are added to the project the bundle sits in, and passes (exit 0) with them.

Not run: `pipx install` (pipx is not installed here), the workflow itself on 1.2.1 or 1.4.0 (the live run used 1.2.4.dev0; superseded by `L-C-R1b.md`), and the bundle catalog over the network.
